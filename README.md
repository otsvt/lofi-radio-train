# Lofi Radio Train

Atmospheric lofi radio with parallax train-window scenes, weather effects and ambient music.

**Live Demo:** https://lofi-radio-train.pages.dev

## About

Lofi Radio Train is an interactive web scene built around the feeling of a quiet train ride.

The project combines animated parallax scenes outside the window, weather switching, lofi music and a minimal control interface. The visual composition is built from separate layers: exterior scene backgrounds, weather effects, window frame, foreground objects, shadows and interface elements are stacked together to create depth and motion.

## Features

- switchable train-window scenes
- rain / snow / clear weather modes
- built-in lofi player with multiple tracks
- audio visualizer
- fullscreen mode

## Tech Stack

- Vue 3
- TypeScript
- Vite
- Tailwind CSS
